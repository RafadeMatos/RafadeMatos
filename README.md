### 🖥️ Sobre mim

> “Para entender como um sistema pode falhar, primeiro é preciso entender como ele funciona.”

💻 **Computer Engineering | Cybersecurity**
🔬 Low-Level Systems • Reverse Engineering • Malware Analysis
⚙️ C/C++ • Assembly • Operating Systems • Computer Architecture

Meu interesse está na interseção entre **sistemas de baixo nível e segurança computacional**.

Atualmente concentro meus estudos em compreender como software e sistemas operacionais funcionam abaixo das abstrações tradicionais — desde a representação de dados e gerenciamento de memória até processos, chamadas de sistema, execução de código e interação com o kernel.

Tenho especial interesse em **engenharia reversa, análise de malware e segurança de sistemas**, utilizando programação e análise de baixo nível como ferramentas para investigar o comportamento de software.

Meu objetivo é construir uma base sólida em **C/C++, arquitetura de computadores, sistemas operacionais e assembly**, avançando progressivamente para pesquisa em vulnerabilidades e segurança de baixo nível.
