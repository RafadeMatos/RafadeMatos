### ⚗️ Sobre mim

> “A estrutura molecular determina a função. A ciência busca compreender essa relação.”

🧪 **Químico & Físico-Químico Computacional**
💊 Drug Discovery • Molecular Modeling • Cheminformatics • Scientific Computing
🐍 Python • Data Science • Machine Learning aplicado às Ciências Moleculares

Atuo na interface entre **Físico-Química**, **Química Computacional** e **Ciência de Dados**, com interesse especial em métodos computacionais para **descoberta e desenvolvimento de fármacos**.

Meu foco é utilizar modelagem molecular, análise de dados químicos e ferramentas de aprendizado de máquina para compreender relações entre **estrutura molecular, propriedades físico-químicas e atividade biológica**, contribuindo para processos de **drug design racional** e otimização de candidatos a fármacos.
